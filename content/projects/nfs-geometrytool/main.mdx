A tool to handle vehicle models in the Black Box NFS games

This tool is currently capable of:
- Parsing and recreating the format from memory
- Exporting cars and other models to .fbx
- Importing vehicle models back into the game
- Converting Most Wanted Xbox 360 models directly into Most Wanted PC and vice versa

## Disclaimer

Due to the current programming landscape, I feel that it's necessary to explicitly state that this project had zero assistance or any other kind of involvement from any sort of "AI agent" and it never will.  
This mod was entirely built by hand, by a human being, and I believe that any project that cannot also claim this about itself is not worth people's time. The only acceptable amount of AI use is zero AI use.

## Usage

- Enter a commandline prompt, run `CwoeeGeometryTool_gcp.exe (filename)` with the arguments you'd like to use (example: `CwoeeGeometryTool_gcp.exe BMWM3GTRE46.fbx -create_mw_bin`)
- The file will now be processed by the tool
- Enjoy, nya~ :3

## Usage (Easy Mode)

- Double click the .exe
- You will now be prompted for a filename, and then the arguments one-by-one (example: `BMWM3GTRE46.fbx`, `-create_mw_bin`)
- The file will now be processed by the tool
- Enjoy, nya~ :3

## Supported formats

- NFS Underground 1 (PC) - Parsing (all model types) & creation (vehicles only)
- NFS Underground 2 (PC) - Parsing (all model types) & creation (vehicles only)
- NFS Most Wanted (PC) - Parsing (all model types + HeliSheet) & creation (vehicles only)
- NFS Most Wanted (Xbox 360) - Parsing (all model types) & creation (vehicles only)
- NFS Most Wanted (PS2) - Parsing (hierarchy & dummies only, no meshes)
- NFS Carbon (PC) - Parsing (vehicles & menu models only) & creation (vehicles only)
- NFS Carbon (Wii) - Parsing only (all model types)
- NFS ProStreet (PC) - Parsing & creation (vehicles only)
- NFS Undercover (Wii) - Parsing only (all model types)
- NFS World (PC) - Parsing & creation (vehicles only)
- NFS Nitro (Wii) - Parsing only (vehicles only)

## Advantages over CarToolkit

- No external configuration files required, materials, normal maps and position markers are all self-contained in the .fbx
- No vertex or polygon limit, models can be as complex as you'd like (requires `-high_poly_support`, does not work for Underground models)
- Position markers are movable & scalable dummies in the .fbx instead of cubes
- ProStreet cars export to .fbx with better UV mapping (they aren't any better in-game though)
- Support for viewing frontend models and even certain types of map models
- Support for the Xbox 360 version of Most Wanted
- Textures are pre-assigned in the .fbx
- Vastly fewer unknown material & texture hashes
- Vertex color data is always preserved

## Limitations

- Autosculpt zone highlighting is not supported in NFS Carbon
- Collision volumes are not supported in the Underground games
- Exported map models do not include section data or positioning data
- Mesh transforms are not preserved, it's recommended to duplicate/merge meshes instead of creating new ones so Blender doesn't break the model
- Wii car models are missing some data, such as vertex colors and autosculpt models

## Arguments

- `-create_ug1_bin` - Exports an .fbx into an Underground 1 car GEOMETRY.BIN file
- `-create_ug2_bin` - Exports an .fbx into an Underground 2 car GEOMETRY.BIN file
- `-create_mw_bin` - Exports an .fbx into a Most Wanted car GEOMETRY.BIN file
- `-create_mw_360_bin` - Exports an .fbx into a Most Wanted Xbox 360 car GEOMETRY.BIN file
- `-create_carbon_bin` - Exports an .fbx into a Carbon car GEOMETRY.BIN file
- `-create_prostreet_bin` - Exports an .fbx into a ProStreet car GEOMETRY.BIN file
- `-create_world_bin` - Exports an .fbx into a World car GEOMETRY.BIN file
- `-export_fbx` - Exports the car into a viewable .fbx file
- `-export_fbx_helisheet` - Exports a map's HeliSheet into an .fbx model
- `-export_text` - Exports the car into a human-readable text file
- `-convert_to_360` - Converts a Most Wanted PC model to Xbox 360
- `-convert_to_pc` - Converts a Most Wanted Xbox 360 model to PC (requires Xbox 360 Stuff Pack)
- `-convert_to_pc_nonormalmap` - Converts a Most Wanted Xbox 360 model to PC (without CARNORMALMAP, works in vanilla)
- `-effect_carnormalmap` - Use EEFFECT_CARNORMALMAP for Most Wanted models, requires Xbox 360 Stuff Pack
- `-high_poly_support` - Allows for meshes with more than 65535 vertices (not supported in Underground 1/2)

## Other Arguments
- `-log_warnings_only` - Only prints errors and warnings into the console
- `-log_errors_only` - Only prints errors into the console
